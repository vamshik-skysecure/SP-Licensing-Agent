# SkySecure Microsoft Licensing Advisor UAT pack

## Purpose

This pack verifies the CEO-approved V1 `simple_pricing` journey using synthetic data:

1. capture a requirement by text, spreadsheet, Word/PDF, image, or voice;
2. allow corrections and require explicit seller confirmation;
3. show the as-submitted annual approved distributor cost;
4. optionally apply a seller-directed SKU or quantity revision;
5. compare Renew As-Is with the revised configuration and confirm the final PDF.

It does not test promotional eligibility, discounts, partner pricing, distributor margin,
automatic bundling, or unsourced migration recommendations. Those are outside V1.

## Data-handling rule

- Use only the supplied synthetic files until privacy/security and business UAT are signed.
- Do not upload customer names, tenant IDs, contracts, or real licence exports through a
  Meta sandbox number or a non-production OpenAI project.
- Keep the seller allowlist limited to named testers.
- Do not enable production until the OpenAI key previously exposed in chat is rotated.
- Never claim an add-on is bundled without an approved business rule.

## Local configuration

```dotenv
RUNTIME_PROFILE=local_demo
ENVIRONMENT=development
STORAGE_MODE=local
WORKFLOW_MODE=simple_pricing
RATE_CARD_LOCAL_PATH=docs/microsoft_sku_v5.xlsx
RATE_CARD_SHEET_NAME=Outcome Sheet
SIMPLE_PRICE_BASIS=distributor_expected
MESSAGE_DISPATCH_BACKEND=direct
AI_INTENT_BACKEND=openai
REQUIREMENT_CAPTURE_BACKEND=openai
OPENAI_MODEL=gpt-5.6-luna
WHATSAPP_VALIDATE_CREDENTIALS_ON_STARTUP=true
```

Start this profile with `scripts/start_local_demo.cmd`; its environment override is limited
to the local process and does not change Azure. Local mode intentionally loses session state
when the process restarts. Production uses Blob-backed sessions with ETag concurrency and a
leased, retrying Blob webhook inbox.

## Automated regression

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\check_tracked_secrets.py
```

Generated local evidence is written under ignored `artifacts/` paths and is not committed.

## WhatsApp acceptance

Follow `V1_SIMPLE_PRICING_UAT.md` exactly and record evidence in
`UAT_EXECUTION_RECORD.md`. Test every supported input channel, corrections before initial
confirmation, as-is pricing, safe fuzzy-match confirmation, seller-directed revision,
comparison, final validation, PDFs received as WhatsApp documents, allowlist rejection,
duplicate delivery, and restart recovery.

## Phase 1 boundary

The active implementation does not depend on the legacy Phase 1 API or source code. It
loads the maintained final `Outcome Sheet` directly and does not assume undocumented Phase 1
behavior.
